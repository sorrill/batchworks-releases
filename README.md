# BatchWorks releases

Installers for BatchWorks, AgriBio Systems' formula, batch and pricing app.

Download the latest version: **[Releases](https://github.com/sorrill/batchworks-releases/releases/latest)**

- Mac: `BatchWorks-<version>-mac.dmg`. Open it, drag BatchWorks into Applications, and open it from there.
- Windows: `BatchWorks-Setup-<version>.exe`.

Once installed, BatchWorks updates itself from this page. This repository holds only the finished installers; no data is stored here.
